# T1 · 立项规划 — 执行协议

## 触发条件
用户说"帮我做 Persona"、"我需要用户画像"、或描述了产品/业务背景希望做用户研究。

## 输入
- 产品/业务描述（必须）
- 团队规模和可投入时间（可选，不给就问）
- 已有用户数据情况（可选）

## 执行步骤

### Step 1：收集必要信息

只问以下问题（缺哪个问哪个）：
1. 你的产品/业务是什么？服务什么场景？
2. 团队大约几个人？有多少时间投入（1周/2周/1个月）？
3. 已有哪些用户数据？（没有也没关系）

### Step 2：评估 & 推荐方法

根据回答，在以下路径中选择：

```
条件 A：已有访谈稿/用户反馈文本
→ 直接进 T3（定性分析）

条件 B：已有问卷/埋点/CRM 数据
→ 直接进 T5（定量分析）

条件 C：两者都有
→ T3 → T5 → T6（混合路径）

条件 D：什么数据都没有 + 时间 < 2周
→ T2（设计访谈）→ 执行 5-8 场 → T3 → T6

条件 E：什么数据都没有 + 时间 ≥ 4周
→ T2（设计访谈）→ T4（设计问卷）→ T3+T5 → T6

条件 F：什么数据都没有 + 时间极短（< 1周）
→ 直接做 Proto-Persona 工作坊 → 输出假设性 Persona（标注"未验证"）
```

### Step 3：输出项目计划

## 产出模板

```markdown
## Persona 项目计划

### 推荐方法：[定性/定量/混合/Proto-Persona]
**理由**：[一句话说明为什么选这个方法]

### 时间线
| 阶段 | 内容 | 时长 | 产出 |
|------|------|------|------|
| W1 | [具体行动] | X天 | [具体交付物] |
| W2 | [...] | X天 | [...] |
| ... | | | |

### 我现在能帮你做的
- [ ] [下一步具体 action——比如"设计访谈提纲"或"分析你的数据"]

### 需要你准备的
- [如果有的话——比如"把访谈录音转成文字"或"导出问卷数据为CSV"]
```

## 自动衔接
- 如果推荐 T2（访谈设计），询问"要我现在就帮你出访谈提纲吗？"
- 如果用户已提供数据，直接进入 T3 或 T5，不再走 T1
