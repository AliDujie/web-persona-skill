# T3 · 定性分析 — 执行协议

## 触发条件
用户提供了访谈文字稿、用户笔记、用户反馈文本、客服对话记录等定性数据。

## 输入
- 文本数据（必须）：访谈稿 / 笔记 / 反馈 / 评论
- 产品背景（可选——如果之前没说过就问一句）

## 执行步骤

### Step 1：提取行为片段

从原始文本中逐条提取**独立的行为/动机/态度/痛点片段**：

```
[P01-行为] 每次预订前至少比较 3 个平台的价格
[P01-动机] "同样的酒店差价可能有 200 块，不比怎么行"
[P01-痛点] 比价费时间，希望有人帮他做好
[P02-行为] 从不比价，朋友推荐什么平台就用什么
[P02-动机] "花那个时间不如多玩一个地方"
```

**提取规则**：
- 每条片段只包含一个信息点
- 标注来源受访者编号（P01/P02/...）
- 区分行为事实 vs 态度观点 vs 痛点
- 保留原话引语（用引号标记）
- 忽略与研究目标无关的闲聊

### Step 2：识别行为变量

从所有片段中归纳"用户在哪些维度上表现出差异"：

```markdown
## 行为变量清单

| 变量名 | 维度描述 | 极端A | 极端B |
|--------|---------|-------|-------|
| 计划程度 | 用户提前多久开始准备 | 提前数月详细规划 | 临时起意 |
| 信息依赖 | 用户如何收集信息做决策 | 自己深度研究 | 依赖他人推荐 |
| 价格敏感 | 价格在决策中的权重 | 核心驱动因素 | 不在意 |
| ... | | | |
```

**变量筛选规则**：
- 只保留有行为意义的维度（行为 > 态度 > 人口统计）
- 确保有足够变异性（至少 2 个受访者在这个维度上不同）
- 确保与产品决策相关（这个差异会影响我们怎么设计产品）
- 最终保留 6-12 个变量

### Step 3：亲和归类

将受访者按行为变量组合进行分群：

```markdown
## 分群过程

### 1. 每位受访者的变量打分
| 受访者 | 计划程度 | 信息依赖 | 价格敏感 | ... |
|--------|---------|---------|---------|-----|
| P01 | 高 | 自研 | 高 | ... |
| P02 | 低 | 他人 | 低 | ... |
| P03 | 高 | 自研 | 中 | ... |

### 2. 分群
- P01 + P03 + P06 → 行为相似（计划型+自研型）→ 群 A
- P02 + P05 + P08 → 行为相似（随性型+依赖型）→ 群 B
- ...
```

### Step 4：产出分群结果

## 产出模板

```markdown
## 分群结果

**方法**：基于 [N] 份访谈的定性行为聚类
**分出**：[K] 个行为群
**核心区分变量**：[变量1]、[变量2]、[变量3]

---

### 群 1：[2-4字行为标签]
- **占比**：[N] / [总数] 受访者
- **核心行为模式**：[2-3 句描述这群人"做什么"]
- **核心动机**：[为什么这么做]
- **典型引语**："[一句代表性原话]"
- **与其他群的关键差异**：[一句话说清楚]
- **对应受访者**：P01, P03, P06

### 群 2：[标签]
- ...

---

### 行为变量清单
| 变量 | 群1 | 群2 | 群3 |
|------|-----|-----|-----|
| [变量名] | [表现] | [表现] | [表现] |
| ... | | | |

---

### 分群质量自检
- [ ] 每个群至少 2 人
- [ ] 用 2-3 个变量就能区分各群
- [ ] 没有"哪个群都放不进去"的受访者
- [ ] 各群内部行为高度一致
```
