# 03 — 定量路径：大样本问卷 + 统计聚类全流程

---

## 一、定量路径适合谁

- 大型组织，需要用数字说服高管或跨部门对齐
- 需要知道"每类用户占市场多少比例"
- 已有大量行为数据（埋点/CRM/交易记录）可补充
- 有统计分析能力的团队成员（或可借调数据分析师）
- 时间 4-8 周，预算较高

**注意**：纯定量路径不如混合路径常见。大多数情况下建议先做定性探索再设计问卷（即混合路径，见 `core/04-mixed-method.md`）。如果你的团队对用户已有一定认知、只是缺少量化验证，可以直接走本路径。

---

## 二、全流程概览

```
问卷设计（W1）→ 数据采集（W2-3）→ 清洗（W3）→ 聚类分析（W4）→ 解读命名（W5）→ 产出
```

## 三、问卷设计

### 3.1 维度选择

问卷题目不是随便出的——需要围绕**行为变量**设计，而非人口统计学。

| 维度类型 | 示例 | 在聚类中的价值 |
|---------|------|--------------|
| 行为频率 | "过去 3 个月你使用XX产品几次？" | 高——直接区分用户类型 |
| 决策因素 | "预订旅行时你最看重什么？（排序）" | 高——揭示价值取向差异 |
| 使用场景 | "你通常在什么情况下使用？" | 高——区分情境型用户 |
| 态度/偏好 | "你对XX的态度是？"（里克特量表） | 中——需配合行为变量 |
| 技术水平 | "你使用这类产品多久了？" | 中——可作辅助维度 |
| 人口统计 | 年龄/性别/收入/城市 | 低——不作为聚类输入，但用于描述 Persona |

### 3.2 问卷结构模板

```markdown
## 问卷结构（建议 40-60 题，10-15 分钟完成）

### Part A · 筛选题（2-3 题）
- 确认目标人群资格
- 不合格者直接终止

### Part B · 行为事实（10-15 题）
- 使用频率、渠道偏好、触发场景
- 里克特 5 点量表 + 单选/多选
- 这是聚类的核心输入

### Part C · 决策因素（5-8 题）
- 关键决策维度排序（MaxDiff 或强制排序）
- 信息来源、比较行为
- 这是区分 Persona 动机的关键

### Part D · 态度与价值观（8-10 题）
- 对品牌/产品/品类的态度量表
- 需求满足度评估

### Part E · 人口统计（5-8 题）
- 放最后——用于描述 Persona 的"长什么样"
- 不参与聚类计算

### Part F · 开放题（1-2 题，可选）
- "还有什么想补充的？"
- 定性素材来源
```

### 3.3 关键设计原则

| 原则 | 做法 | 反面 |
|------|------|------|
| 行为优先于态度 | 问"你做了什么"而非"你觉得怎么样" | 全是满意度题 |
| 避免社会期望偏差 | 用间接/行为化的问法 | "你环保吗？"（人人说是） |
| 控制题量 | 40-60 题上限 | 100 题（完成率暴跌） |
| 量表一致性 | 全部用 5 点量表，不要混用 5/7/10 | 忽左忽右让受访者混乱 |
| MaxDiff > 重要性评分 | 强制取舍更能区分真正优先级 | "以下哪些重要？"（全部勾选） |
| 先 Pilot | 找 15-20 人试答 → 检查完成时长和弃答率 | 直接大规模发放 |

## 四、样本量与采集

### 4.1 样本量计算

| 聚类方法 | 最低样本 | 建议样本 | 说明 |
|---------|---------|---------|------|
| K-Means | 100 | 300-500 | 变量越多需要越大样本 |
| 潜在类分析 (LCA) | 200 | 500-1000 | 对样本量更敏感 |
| 因子分析 + 聚类 | 变量数 × 5-10 | 300+ | 先降维再聚类 |

**经验法则**：变量数 × 10 = 最低样本量。如果你有 30 个行为变量，至少需要 300 份有效问卷。

### 4.2 采集渠道

| 渠道 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| 产品内嵌问卷 | 精准、真实用户 | 打扰体验 | 现有用户调研 |
| 邮件/短信邀请 | 可定向发送 | 回收率低（5-15%） | 有用户数据库 |
| 第三方样本库 | 量大、快速 | 样本质量参差 | 覆盖非用户 |
| 线下拦截 | 场景真实 | 效率低、成本高 | 特定场景研究 |

### 4.3 数据清洗

发放后必须清洗——脏数据会严重影响聚类结果：

| 清洗规则 | 说明 |
|---------|------|
| 完成时间过短 | 全卷 < 3 分钟 → 删除（大概率随机填） |
| 直线作答 | 连续 10+ 题选同一选项 → 删除 |
| 矛盾答案 | 设置 2-3 道互相验证的题，不一致 → 删除 |
| 缺失值 > 30% | 关键变量空值超过 30% → 删除该样本 |
| 开放题胡答 | "asdf" 或完全无关内容 → 标记可疑 |

## 五、聚类分析

### 5.1 三种主要方法

| 方法 | 原理 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| K-Means | 最小化簇内距离 | 简单快速、结果稳定 | 需预设 K、对球形簇假设 | 连续变量为主 |
| 潜在类分析 (LCA) | 概率模型、最大似然 | 可处理分类变量、有统计检验 | 计算复杂、需大样本 | 混合变量/需严谨统计 |
| 因子分析 + K-Means | 先降维再聚类 | 降噪、可解释 | 两步各有误差 | 变量多(30+) |

### 5.2 确定最优 K（聚几类？）

不要拍脑袋决定！用数据说话：

| 方法 | 做法 | 判断标准 |
|------|------|---------|
| 肘部法则 (Elbow) | 画 K vs 组内平方和图 | 拐点处的 K |
| 轮廓系数 (Silhouette) | 计算每个 K 的轮廓分 | > 0.25 可接受，> 0.5 好 |
| BIC/AIC（LCA 用） | 信息准则对比各 K | 最小 BIC 对应的 K |
| Gap Statistic | 与随机分布对比 | 首次超过随机 + 1 标准误的 K |
| 业务可用性 | 3-5 个团队能记住 | 结合统计 + 实用判断 |

**黄金法则**：统计最优 ≠ 业务最优。如果统计说 7 类最好，但 4 类也能解释 85% 的差异——选 4。

### 5.3 稳定性检验

聚类结果不能只跑一次就信：

| 方法 | 做法 |
|------|------|
| Bootstrap | 有放回抽样 1000 次，看每次结果是否一致 |
| 分半验证 | 数据随机拆成两半，分别聚类，对比结果 |
| 不同初始值 | K-Means 跑 50 次不同种子，看是否收敛 |
| 判断标准 | 稳定性 > 80% 可接受 |

## 六、从统计结果到 Persona

聚类分析产出的是数字——一组"第 1 类用户平均值是…第 2 类是…"。还需要以下步骤变成 Persona：

### 6.1 剖面解读

对每个簇，画出"雷达图/柱状图"展示各变量均值差异，然后回答：

| 问题 | 目的 |
|------|------|
| 这群人的行为特征是什么？ | 识别核心标签 |
| 他们最看重什么？ | 确定核心动机 |
| 他们和其他群体最大的差异在哪？ | 找到区分度 |
| 他们占总样本多少比例？ | 评估市场规模 |

### 6.2 命名与叙事化

统计聚类需要"翻译"成人能记住的 Persona：

```
第 1 类（23% 样本）
  · 高频使用 + 价格敏感 + 计划型 + 多平台比较
  → 命名："精算旅行家"
  → 一句话：频繁出行但精打细算，每次预订至少比较3个平台

第 2 类（31% 样本）
  · 低频使用 + 体验驱动 + 即兴型 + 品牌忠诚
  → 命名："随性体验派"
  → 一句话：一年出行1-2次但追求品质，选定品牌后不再比价
```

### 6.3 补充定性素材

纯定量 Persona 缺乏"血肉"——建议在统计分群之后，从每个簇中抽取 2-3 人做深度访谈，获取：

| 补充内容 | 作用 |
|---------|------|
| 真实故事 | 让 Persona 有画面感 |
| 原话引语 | 增加可信度 |
| 情境细节 | 理解"为什么"数字是这样 |
| 照片/场景描述 | 团队更容易共情 |

## 七、产出报告结构

```markdown
## 定量 Persona 报告结构

### 1. 研究概览
- 目标、方法、样本量、采集周期

### 2. 聚类方法与验证
- 选用方法及理由
- K 的确定过程（含图表）
- 稳定性验证结果

### 3. 每个 Persona（各占 1 页）
- 名称 + 一句话描述 + 市场占比
- 核心变量雷达图
- 与其他 Persona 的关键差异（2-3 条）
- 典型用户引语（来自补充访谈）
- 对产品决策的启示

### 4. Persona 对比总览
- 多 Persona 对比表
- 适用场景建议

### 5. 方法局限与建议
- 哪些发现需要进一步验证
- 何时更新（建议每年重新采集）
```

## 八、定量路径常见错误

| # | 错误 | 后果 | 预防 |
|---|------|------|------|
| 1 | 只用人口统计聚类 | 得到"年轻女性"而非有行为意义的 Persona | 用行为变量做聚类输入 |
| 2 | 样本量不足 | 聚类不稳定、换个种子结果就变了 | 至少 300 样本 |
| 3 | 不做稳定性检验 | 以为 5 类最优其实只是随机 | Bootstrap + 分半验证 |
| 4 | K 只看统计不看业务 | 统计最优 8 类但团队记不住 | 结合统计和实用性 |
| 5 | 产出只有数字没有故事 | 团队无法共情和使用 | 补充定性访谈 + 叙事化 |
| 6 | 不清洗数据就聚类 | 噪声数据污染结果 | 严格清洗规则 |

---

## 九、本章核心要点

1. **行为变量聚类 > 人口统计聚类**——用"用户做什么"而非"用户是谁"分群
2. **样本量要够**——变量数 × 10 是底线
3. **K 的选择 = 统计 + 业务判断**——宁少不多
4. **稳定性检验是必须的**——不能只跑一次就信
5. **纯数字不够**——必须用叙事补充"血肉"
6. **定量优势在于"占比"和"说服力"**——知道每类用户有多大市场
