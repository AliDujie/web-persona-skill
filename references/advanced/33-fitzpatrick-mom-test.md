## 一、核心定位

这本书只有 130 页，却是"如何不被受访者骗"的终极指南。Portigal 教你怎么做好深度访谈，Fitzpatrick 教你怎么**不做坏访谈**——尤其是当你满脑子产品假设、迫切想听到"好好好"时。

### 1.1 Mom Test 三条铁律

| # | 铁律 | 解释 |
|---|---|---|
| 1 | 谈**他们的生活**，不谈你的想法 | 禁止 pitch，禁止描述产品然后问"你觉得怎么样？" |
| 2 | 问**过去的具体行为**，不问未来的意愿 | "你上次遇到这个问题时做了什么？" ≫ "你会不会用X？" |
| 3 | 少说多听，然后**推进到承诺** | 有价值的对话应以对方给出时间/金钱/声誉承诺结束 |

### 1.2 与 Persona Skill 整合逻辑

Mom Test 式对话生成的是**行为事实**（过去做了什么、花了多少钱、找了哪些替代方案），正好是 Persona 行为变量矩阵的最干净输入——不需要二次去噪。

## 二、好问题 vs 坏问题

### 2.1 坏问题特征

| 特征 | 示例 | 为什么坏 |
|---|---|---|
| 假设性/意愿性 | "你会为X付费吗？" | 人人说"会"，没人真掏 |
| 赞美诱导 | "我们做了个很酷的功能…" | 对方出于礼貌夸你 |
| 泛泛抽象 | "你一般怎么旅行？" | 得到的是"应该如何"而非真实行为 |
| 自证预言 | "你是不是也觉得XX很烦？" | Leading question |

### 2.2 好问题公式

```
好问题 = 过去时 + 具体事件 + 不含你的产品

"上次你 [做某事] 时，遇到最烦的一步是什么？"
"你当时是怎么解决的？花了多少时间/钱？"
"为什么还没换掉现在的方案？"
```

### 2.3 五类核心好问题

| # | 问题 | 探测目标 |
|---|---|---|
| 1 | "你能跟我讲讲上次……的经历吗？" | 真实行为流 |
| 2 | "最让你头疼的部分是什么？" | Pain point 排序 |
| 3 | "你现在怎么处理这件事？" | 现有替代方案/竞品 |
| 4 | "这件事上你花了多少钱/时间？" | Willingness to pay 代理指标 |
| 5 | "还有谁也该聊聊这个？" | Referral + 社群验证 |

## 三、三种不良会议 & 修复

| 类型 | 症状 | 修复 |
|---|---|---|
| Compliment Session | "哇这个主意太棒了！" | 回到过去行为："谢谢，不过你上次遇到这问题时实际做了什么？" |
| Fluff Session | 大量观点但无事实 | 锚定具体事件："能给我举个最近的例子吗？" |
| Pitch Meeting | 你说80%、对方说20% | 闭嘴；把话筒还给对方 |

## 四、承诺与推进（Commitment & Advancement）

### 4.1 三类承诺（递增信号强度）

| 承诺类型 | 示例 | 信号强度 |
|---|---|---|
| Time | "下周再聊一次""来参加我们的 beta 测试" | ★★☆ |
| Reputation | "我帮你介绍我同事/老板" | ★★★ |
| Money | "这个我愿意预付""给我invoice" | ★★★★★ |

### 4.2 判断对话是否有价值

```
对话后问自己：
✅ 我学到了什么新的、违反直觉的事实？
✅ 对方给了什么具体承诺（时间/声誉/钱）？
❌ 如果两者皆无 → 这次对话浪费了
```

## 五、寻找对话对象（Customer Segments）

### 5.1 三步瞄准

| 步骤 | 方法 |
|---|---|
| 1. 画 Customer Segment | 谁最痛？谁最有钱？谁最容易找到？ |
| 2. Vision → First Customer | 不是"所有人都会用"，而是"谁**今天**就会买？" |
| 3. Slicing | 切到足够小——"上海25-35岁、每月出差3次以上的产品经理" |

### 5.2 冷启动找人渠道

| 渠道 | 适合 | 不适合 |
|---|---|---|
| 行业社群/Slack/微信群 | 精准、免费 | 需先建立存在感 |
| Landing Page + Survey | 量大 | 深度不足 |
| 朋友的朋友（warm intro） | 信任高 | 样本偏 |
| 会议/Meetup 蹲守 | 面对面深度 | 效率低 |
| LinkedIn Cold DM | B2B 精准 | 回复率 <5% |

## 六、笔记与归档系统

### 6.1 Fitzpatrick 笔记三原则

1. **现场只记关键引语和情绪**（不要把头埋在笔记本里）
2. **会后 15 分钟内**把未写下的细节补完（短期记忆窗口）
3. **用 Meta-labels 标记每条笔记**：

```
[P] = Pain（痛点）
[B] = Behavior（实际行为）
[$] = Money signal（付费信号）
[R] = Request（功能请求——高度可疑，需追问背后的 Job）
[C] = Commitment（给了承诺）
[!] = Surprise（违反预期）
```

### 6.2 笔记 → Persona 输入映射

| Meta-label | Persona 维度 |
|---|---|
| [P] | Pain Points |
| [B] | Behavioral Variables |
| [$] | Willingness to Pay / Budget |
| [R] | Stated Needs (vs. Latent Needs) |
| [C] | Engagement Level |
| [!] | Differentiation Insight |

## 七、团队协作 & 知识扩散

### 7.1 避免"信息瓶颈"

> 如果只有一个人做了所有访谈，团队其他人只看到"结论"而非"原始信号"——这和没做区别不大。

| 方法 | 操作 |
|---|---|
| Pair Interviews | 两人一组（Lead + Note-taker） |
| Weekly Debrief | 每周 30 min 全团队分享 Top 3 Surprises |
| Quote Wall | 把最震撼的原话贴在物理墙/Miro上 |
| Learning Cards | 每次对话后写一张 "We learned that…" 卡 |

## 八、与 Persona 反模式的关系

| Persona 反模式 | Mom Test 对应修复 |
|---|---|
| Elastic User（弹性用户） | 用 Slicing 锚定"第一个真实客户" |
| Design-by-Committee | 用承诺区分真需求 vs 噪声 |
| Self-Referential Persona | 用"他们的生活"替代"你的假设" |
| Zombie Persona（僵尸画像） | 持续对话 + 承诺验证保持画像鲜活 |
| 功能请求堆砌 | [R] 标记 → 追问 "上次因为没有这个功能你放弃了什么？" |

## 九、实操模板

### 9.1 10 分钟快速验证对话模板

```markdown
**开场**（30s）：
"谢谢你的时间。我在研究 [领域]，想了解你的真实经历。没有对错答案。"

**核心三问**（8min）：
1. "你上次 [做X] 是什么时候？能跟我讲讲那次经历吗？"
2. "在那个过程中，最让你头疼/花时间最多的是哪一步？"
3. "你当时怎么解决的？试过什么替代方案？效果如何？"

**承诺推进**（1.5min）：
"如果我做了一个解决 [痛点] 的东西，你愿意花 10 分钟试试 beta 版吗？"
"你觉得谁也会关心这个问题？能帮我引荐一下吗？"
```

## 十、常见陷阱总结

| # | 陷阱 | 表现 | 对策 |
|---|---|---|---|
| 1 | 寻求认可 | "你觉得这个想法好吗？" | 删掉所有 pitch 环节 |
| 2 | 过早泄露方案 | 描述产品细节 | 只在获得 3+ 个痛点事实后才提方案 |
| 3 | 不追问 | "哦好的" 就换话题 | 每个痛点至少追 2 层 "然后呢？" |
| 4 | 只和好说话的人聊 | Survivor Bias | 必须找"已流失/未使用"的人 |
| 5 | 无笔记归档 | 做了 20 次访谈但记不清细节 | 15 min 内归档 + Meta-label |
| 6 | 样本为 1 | 一个人说痛就当真 | 至少 3 个独立验证相同 pain |
| 7 | 团队信息孤岛 | 只有研究员知道 insight | Weekly Debrief + Quote Wall |

## 本部分核心要点总结

1. **Mom Test 的精髓**：永远谈对方的过去行为，永远不问"你会不会用我的产品"
2. **承诺是唯一的验证货币**：对方愿意给时间/声誉/钱，才说明需求是真的
3. **好问题不含你的产品**：一旦对话变成 pitch，数据就污染了
4. **15 min 归档纪律**：用 [P][B][$][R][C][!] 六标记快速编码，直接映射 Persona 维度
5. **Slicing 到可触达**：Persona 的颗粒度应该小到"你能在这周找到 5 个这样的人聊"
